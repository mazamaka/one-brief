# Один бриф — разные модели

Стенд: один и тот же бриф сайта уходит разным моделям без правок, работы складываются сюда
и сравниваются по брифу. Витрина: https://mazamaka.github.io/one-brief/

| Раунд | Что | Аудит |
|---|---|---|
| 02.11.2026 | Клуб силовой подготовки, 5 моделей, копии сайтов и оценки | [AUDIT.md](rounds/2026-11-02-fitness/AUDIT.md) |
| 08.09.2026 | Три брифа × четыре модели, ссылки на оригиналы | [AUDIT.md](rounds/2026-09-08-three-briefs/AUDIT.md) |

## Как устроено

- `assets/data.js` — все раунды, работы и оценки; витрина `index.html` собирается из него.
- `rounds/<раунд>/sites/<модель>/` — копия работы: файл как есть, зеркало или отрисовка
  (как именно — в поле `note` у работы).
- `rounds/<раунд>/shots/<модель>-hero.jpg` (1440×900 → 1200×750) и `-mobile.jpg` (390×844) —
  первые экраны для карточек.
- `rounds/<раунд>/prompt.txt` — промпт без изменений.

## Добавить модель в раунд

1. Положить сайт в `rounds/<раунд>/sites/<slug>/index.html`.
2. Снять первые экраны на 1440×900 и 390×844 в `rounds/<раунд>/shots/<slug>-hero.jpg` и `<slug>-mobile.jpg`.
3. Дописать объект в `entries` раунда в `assets/data.js`: оценки 1–10 по шести критериям,
   плюсы, минусы, ссылка на оригинал. Место в рейтинге посчитается само.
